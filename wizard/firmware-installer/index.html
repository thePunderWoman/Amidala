Enter bootloader mode

The ESP32-S3's USB port has no auto-reset circuitry, so you'll need to put it into bootloader mode by hand before connecting:

  1. Plug the board in over USB, if it isn't already.
  2. Hold the BOOT button.
  3. Tap and release RESET (while still holding BOOT).
  4. Release BOOT.
  5. Click Connect below and select the board's serial port.
⚠ Before you flash This installs fresh firmware and erases all saved settings on the board (WiFi credentials, config, calibration) — this is meant for first-time setup or a full reset, not an incremental update. Do not disconnect the board once flashing starts.
